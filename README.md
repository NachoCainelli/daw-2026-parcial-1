# El Pulso Regional

Portada original de un diario digital desarrollada para el Trabajo Practico N.º 1 - Flexbox.

## Tecnologias

- HTML semantico.
- CSS externo.
- Flexbox como herramienta principal de layout.
- Responsive Design con enfoque Mobile First.

## Publicacion

GitHub Pages: https://nachocainelli.github.io/daw-2026-parcial-1/

> El enlace funcionara cuando la rama se suba al repositorio y se habilite GitHub Pages.

## Estado del desarrollo

El desarrollo inicial del portal se esta llevando adelante en la rama `dev-portal`.

## Nomenclatura de ramas

- `dev-{funcionalidad}`: desarrollos de funcionalidades nuevas.
- `fix-{error}`: correccion de errores.
- `imp-{funcionalidad}`: mejoras o cambios de funcionalidades existentes.
